# Cubism SDK for Web 5 R5 runtime assets

This directory contains the production Cubism 5 R5 Web runtime used by the MOC3 display.

- runtime.js: production bundle built from Live-Danmaku-Bot's Cubism SDK for Web 5 R5 integration, with shader URLs redirected to this directory and unrelated live-TTS polling disabled.
- Core/live2dcubismcore.min.js: Live2D Cubism Core production runtime.
- Framework/Shaders/WebGL/: official Cubism Web Framework WebGL shader sources.

Source project: https://github.com/dongguo4812/Live-Danmaku-Bot
SDK version: Cubism SDK for Web 5 R5
